Subscribe to delivery problems. Choose an alert channel independent of the primary delivery channel.

This design study illustrates the settings now available in My profile. Shared administrator rules remain in Failure alerts.

How it works

01 · Provider error

The interface shows the reason and Retrying state immediately. A temporary failure does not mean the message is lost.

02 · Delivery retries

The current mechanism attempts delivery up to 5 times. Subscription conditions determine when to send an alert.

03 · Separate alert queue

One warning per incident, grouped failures and a cooldown. Failures in the alert queue never trigger more alerts.
